1.2 Equations of Lines

Starting onPg. 7
Expression

an expression consists of numbers, variables, & arithmetic operations

Ex: \(3x+2\)
Equation

two expressions set equal
make an equation

Ex: \(3x+2=4\)
Exponent

an exponent represents the number of times a value is multiplied by itself

\(a^b = \underbrace{a\times a\times ...\times a}_{b\text{ many times}}\)

Ex: \(3^4 = 3\times 3\times 3\times 3\)
Degree

the degree of an expression/equation is the highest exponent on the variable

Ex: \(3^4 + 2x +7\) is degree 4
Linear

an equation is linear if it is degree 1

AKA the highest exponent is 1
Ex: \(5x + 2\) is a linear expression

Example 3b: Traditional Method

Determine line with points \((-1,3)\) and \((1,-1)\).

  1. find slope \(m\)

    \(m= \dfrac{3-(-1)}{-1-1} = \dfrac{4}{-2} = -2\)

  2. plug one point to solve for \(b\)

    \(y = mx + b\) using \((1,-1)\)

    \((-1)=-2(1) + b\)

    \(-1+2=b\)

    \(1=b\)

    \(y=-2x+1\)
