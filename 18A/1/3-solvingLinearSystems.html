Solving by Substitution

  1. Isolate one variable: solve one equation for one variable.

    Pick the easier one!!

  2. Substitute: replace the variable you isolated in the other equation.

    You should now have only one variable in your eq.

  3. Back-substitute: plug the (2) answer into the (1) answer to find the other variable.

  4. Check your solution in BOTH eqs!

How many answers does a linear system have?

3 Cases (Graphically)

  • exactly 1 solution:

    different slope

  • no solutions:

    same slope, different intercepts

  • infinite solutions:

    same slope, same intercepts
    (same line!)

3 Cases (Numerically)

  • exactly 1 solution:

    get specific \(x\) and \(y\)

  • no solutions:

    variables cancel out and result is FALSE

  • infinite solutions:

    variables cancel out and result is TRUE
