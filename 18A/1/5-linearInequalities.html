Linear Inequality

a linear inequality is two linear expressions combined using an inequality symbol

like a linear equation except an inequality instead of an equal sign
Ex: \(5 > 2\)

Solving Linear Inequalities

  • goal: isolate \(x\) on one side

  • same rules:

    • what you do to one expression, you must do to the other

    • \(+,-,\times, \div,\) etc. are all valid

    • EXCEPTION: you have to flip the symbol when you multiply by a negative number

      \( \left[ 3 < 5\right] \times -1 = -3 > -5\)

Compound Inequalities

Compound Inequality

a compound inequality is three expressions combined using (directionally consistent) inequality symbols

Ex: \(1 < x < 5\)
\(1 < x > 5\) is NOT correct

Solving Compound Linear Inequalities

  • goal: isolate \(x\) in the middle

  • same rules:

    • what you do to one expression, you must do to all others

    • \(+,-,\times, \div,\) etc. are all valid

    • EXCEPTION: you have to flip all symbols when you multiply by a negative number

      \( \left[ 1 < x < 5\right] \times -1 = -1 > x > -5\)
