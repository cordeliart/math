3.1 Intro to Functions

Starting onPg. 80
Function

a function (of \(x\)) is an equation that assigns each element in the domain to exactly one element in the range

Inputs & Domain

an input is a value that can go into a function

the domain is the collection of all inputs

Outputs & Range

an output is a value produced by a function

the range is the collection of all outputs

Function Notation

\(f(x)\) is read “f of x”

We can also use other letters, like \(g(x)\) or \(h(x)\).

Function Notation

If we say “Let \(f(x)=...\)”, the \(...\) is what we use to define our function, using \(x\) as a placeholder for the input

\(f(x)\) does NOT mean \(y\)!

We used \(y\) as a variable, but a function is NOT a variable. Instead, think of a function as a machine that takes in an input, does something to it, and spits out an output.

What to do with \(f(\#)\)

\(f(\#)\) means plugging # into the equation for \(x\). (It does NOT mean “f times #” or “f times x”!)

Here, # is your input!
