3.1 Intro to Functions

Starting onPg. 80
Function

a function of \(x\) is an equation that assigns each element in the domain to exactly one element \(y\) in the range

Inputs & Domain

an input is a valid \(x\) that you can put in a function, and the domain is the collection of all inputs

Outputs & Range

an output is a \(y\) produced by a function, and the range is the collection of all outputs

Function Notation

\(f(x)\) is read “f of x”

\(f(x)\) means plugging into the equation for \(x\). It does NOT mean “f times x”!

\(f(x)\) does NOT mean \(y\)!

We used \(y\) as a variable, but a function \(f(x)\) is not a variable.

Instead, think of a function as a machine that takes in an \(x\), does something to it, and spits out a \(y\).

Example 2

Let \(f(x)=x+1\). Evaluate \(f(2)\).

\(f(2)\) means we plug in \(x=2\).

\(f(2) = 2 + 1\) \(=\) \(3\)

What to do with \(f(x)=y\)

Remember, the thing we plug in is the input, and the result is the output. Here, we treat \(x\) and \(y\) like their own variables, not related to the function \(f\).

If it’s easier, you can imagine it as \(f(a) = b\) instead.

Let’s update the “output” definition with this new notation: the outputs are the \(f(x)\)-values which can be given by the function. This means \(f(x)\) stays together, almost like a new variable, and as one object can be equal to a numerical value. Thus when you are given \(f(x) = y\) it is basically saying “for some input \(x\), the output is this \(y\).” You set the equation equal to that number as the output, and then solve as usual.
