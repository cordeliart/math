3.6 Inverse Functions

Starting onPg. 109

Functions are machines.

An inverse function is a machine that UNDOES a function.

Functions are machines.

An inverse function is a machine that UNDOES another function. They cancel each other out.

Let’s think about putting on socks and shoes. If I want to undo that, what do I do?

Take off shoes, then take off socks.

Notice that we do the opposite actions in REVERSE order!!

Now let’s think about \(x^2\). If I want to undo that (to get back to \(x\)), what do I do?

Take the square root.
\(\sqrt{?}\)

How about \(x^2+4\). If I want to undo that (to get back to \(x\)), what do I do?

Remember, we do the opposite actions in REVERSE order!!

Subtract four, then square root.
\(\sqrt{?-4}\)

Inverse Function

two functions \(f(x)\) and \(g(x)\) are inverses of each other when \( f(a)=b \phantom{.}\) means \(\phantom{.} g(b)=a\),
and vice versa, for any \(a\) and \(b\)

Not every function has an inverse!!

Notation

Instead of vaguely saying \(f(x)\) and \(g(x)\), we write \(f(x)\) and \(f^{-1}(x)\)!

\(f^{-1}\) is NOT an exponent; this is the notation for inverse, which is read "f inverse."

Inverse Function: Updated Notation

two functions \(f(x)\) and \(f^{-1}(x)\) are inverses of each other when \( f(a)=b \phantom{.}\) means \(\phantom{.} f^{-1}(b)=a\),
and vice versa, for any \(a\) and \(b\)

Not every function has an inverse!!

Inverting: Step by Step

  1. Rename the eq \(f(x)=...\) as \(y=...\) to make it easier to work with.

    Replace \(f(x)\) with \(?\), or some other placeholder.

  2. Solve the equation for \(x\).

    Isolate \(x\).

  3. Make a new equation by swapping \(x\) and \(y\) in that result.

    Swap \(x\) and \(?\).

  4. Rename the resulting \(y=...\) to \(f^{-1}(x)=...\)

    Replace \(?\) with \(f^{-1}(x)\).

  5. Check your answer. \(\checkmark\)

Checking Inverses

\( f^{-1}\big( {\color{#386ef6} f(x)} \big) = x \)
\( \color{#386ef6} f\big( {\color{#111111} f^{-1}(x)} \big) = x \)
\( (f^{-1} \circ {\color{#386ef6} f})(x) = x \)
\( ({\color{#386ef6}f}\circ f^{-1} )(x) = x \)

Checking Inverses

To verify that your functions are actually inverses, you must check:

$$ (f^{-1} \circ {\color{#386ef6} f})(x) = x $$

AND

$$ ({\color{#386ef6}f}\circ f^{-1} )(x) = x $$

Comparing Graphs

The graph of the inverse \(f^{-1}(x)\) will look like \( f(x)\) flipped across the diagonal (\(x=y\)).

This is because any point \((a,b)\) for \(f(x)\) will have a corresponding point \((b,a)\) for \(f^{-1}(x)\). Basically, we swap all of our ordered pairs; we can also think of this as swapping our axes.

What makes a function invertible?

One-to-One

a function is one-to-one if each input makes a unique output

This property is necessary for a function to have an inverse!
Horizontal Line Test

the horizontal line test checks whether a function is one-to-one; scan the graph with a horizontal line, and if it hits more than once, it FAILS
