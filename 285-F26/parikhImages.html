Parikh Images
& Semilinearity

Let \(L \subseteq \{ a_1, a_2, ..., a_n\}^*\) be a language.

Let \(w\) be a word in the language \(L\).

Parikh Images

Parikh Image

the Parikh image, or length characteristic, of a word \(w\) is a vector whose entries count the occurrences of every symbol

\( \psi(w) = \big\langle \psi_{a_1} (w), . . ., \psi_{a_k} (w) \big\rangle \)

\( \psi_{a_i} (w) \) is the # of occurrences of \(a_i\) in \(w\)
Example 1

Let \(L \subseteq \{a,b,c\}^* \). What is \( \psi( aabba) \)?

\( \psi(aabba) = \langle 3,2,0 \rangle \)

Parikh Image

the Parikh image, or length profile, of a language \(L\) is the set of all Parkih images (vectors) of its words

\( \psi(L) = \{ \psi(w) \mid w\in L\} \)

Example 2

Let \(L \subseteq \{a,b\}^* \) be the language consisting of words of the form \( a^n b^m\) with \(n,m\geq 0 \). What is \( \psi(L) \)?

\( \psi(L) = \big\{ \langle n,m \rangle \mid n,m\in\mathbb{N}_0 \big\} \)

\( \phantom{\psi(L)} = \big\{ \langle 0,1 \rangle, \langle 1,0 \rangle, \langle 1,1 \rangle, ... \big\} \)

Example 3

Let \(L \subseteq \{a,b,c\}^* \) be the language consisting of words \( a^n b^n c^n\) with \(n \geq 0 \). What is \( \psi(L) \)?

\( \psi(L) = \big\{ \langle n,n,n \rangle \mid n\in\mathbb{N}_0 \big\} \)

\( \phantom{\psi(L)} = \big\{ \langle 0,0,0 \rangle, \langle 1,1,1 \rangle, \langle 2,2,2 \rangle, ... \big\} \)

Semi-Linearity

Linear Set

a set \(A \subseteq \mathbb{N}_k \) is linear if there are \( u_0, u_1, ..., u_m \in \mathbb{N}_k \) such that

\( A = \{ u_0 + \sum^m_{i=1} c_iu_i \mid c_1, ..., c_m \in \mathbb{N} \} \)

Semilinear Set

a set \(\subseteq \mathbb{N}^k \) is semilinear if it is a finite union of linear sets; closed under selection and projection

Semilinear Language

a language \( L\) is semilinear if and only if its Parikh image is a semilinear subset of \(\mathbb{N}^k\)

Trees of CFGs

Let \(G (N, \Sigma, P, S) \) be a CFG.

Parse Tree

a parse tree is any tree that meets the following requirements:

  1. every non-leaf label = nonterminal \(A\) (and \(G\) has a production \(A\rightarrow \alpha\) that is the string = labels of its children from L to R)

  2. every leaf label = terminal or \(\varepsilon\) (where any \(\varepsilon\)-labelled has no sibling)

  3. root label = start symbol

Initial Parse Tree

an initial parse tree is a parse tree where no distinct nodes on the same path share the same label

Pump

a pump is a tree with at least two nodes that meets the following requirements:

  1. every non-leaf label = nonterminal \(A\) (and \(G\) has a production \(A\rightarrow \alpha\) that is the string = labels of its children from L to R)

  2. every leaf label = terminal or \(\varepsilon\) (where any \(\varepsilon\)-labelled has no sibling), except for one that is labelled by the same nonterminal as root

  3. root label = start symbol

Spine

the spine of a pump is the path from the root to the nonterminal-labelled leaf

Basic Pump

a basic pump is a pump where no distinct nodes on the spine or on a path disjoint from spine share the same label

In a \(\text{CFG}\), there are only finitely many initial parse trees and basic pumps.

Root

the root of a pump \(\nu\) is denoted \( \text{root}( \nu )\)

Nonterminals

the set of nonterminals of a parse tree \(\tau\) (or a pump) are denoted \( \text{nont}(\tau) \)

Pump Sequence

We write \(\tau \overset{\nu}{\triangleleft} \tau'\) if \(\tau'\) is the result of adjoining \(\nu\) at a node of \(\tau\) labelled by \(\text{root}(\nu)\).

This can extend to multiple pumps: \(\tau \overset{\nu_1,...,\nu_n}{\triangleleft} \tau'\).

We call this a pump sequence, denoted \( (\tau, \nu_1, \nu_2, ..., \nu_n) \).

Pump Sequence

  • \(\tau \overset{\nu}{\triangleleft} \tau'\) is valid \(\iff \text{root}(\nu) \in \text{nont}(\tau) \)

  • \(\tau \overset{\nu_1,...,\nu_n}{\triangleleft} \tau' \implies \text{nont}(\tau')\)
    \(= \text{nont}(\tau) \cup \text{nont}(\nu_1) \phantom{.}\cup\phantom{.} ... \cup \text{nont}(\nu_n) \)

Kanazawa 5.7

If \( (\tau, \nu_1, \nu_2, ..., \nu_n) \) is a valid pump sequence, then...

  • truncated is valid: \( (\tau, \nu_1, \nu_2, ..., \nu_{i< n} ) \)

  • skipped duplicates is valid: \( (\tau, \nu_1, \nu_2, ..., \nu_{j-1}, \nu_{j+1}, ..., \nu_n ) \) if \(\nu_j=\nu_i\)

Kanazawa 5.8

Let \(\tau\) be an initial parse tree.

Then \( \{ \psi(\tau ') \mid \tau \triangleleft \tau' \} \) is semilinear.

Parikh, 1966

If \(L\) is a CFL, then its Parikh image \( \{ \psi(w) \mid w \in L \} \) is semilinear.

Trees of MCFGs

Let \(G (N, \Sigma, P, S) \) be a MCFG, where each rule is of the form:

\( B (\alpha_1, ..., \alpha_r) \leftarrow B_1(x_{1,1}, ..., x_{1,r_1}), ..., B_n(x_{n,1}, ..., x_{n,r_n}) \)

Derivation Tree

a derivation tree is any tree that meets the following requirements:

  1. every node is labeled by a rule

  2. children correspond (each node labelled by the rule
    \( B (\alpha_1, ..., \alpha_r) \leftarrow B_1(x_{1,1}, ..., x_{1,r_1}), ..., B_n(x_{n,1}, ..., x_{n,r_n}) \) has \(n\) children, and the \(i\)th child is of type \(B_i\))

Derived String

the derived string of a derivation tree, denoted \(\text{distr}(\tau)\) is:

\( \text{distr}(\tau) = (\alpha_1, ..., \alpha_r)\sigma \)

where \(\sigma\) maps \(x_{i,j}\) to \(w_{i,j}\)
Vijay-Shanker, 1987

If \(L\) is an MCFL, then its Parikh image \( \{ \psi(w) \mid w \in L \} \) is semilinear.
