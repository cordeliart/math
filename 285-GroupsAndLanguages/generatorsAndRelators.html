Generators & Relators

Let \(G\) be a set and \(*\) be an operation such that:

  • \(G\) is closed under the associative,
    binary operation \(*\) ➔ “semigroup”

  • and \(G\) contains an identity element \(e\) such that
    \(ge = g = eg\)   \(\forall g\in G\) ➔ “monoid”

  • and \(G\) contains an inverse element \(g^{-1}\) for every element \(g\in G\) such that \(gg^{-1}=e=g^{-1}g\) ➔ “group”

A group \(G\) is generated by elements \(a_1, a_2, ...\) if every \(g\) in \(G\) can be written as a combination of those elements, called generators

  • a group is finitely generated if the set of generators \(X\) is finite

  • \(G = \langle a_1, a_2, \ldots \rangle = \langle X \rangle \)

Some Textbook Terminology

Given an alphabet \(A\) generated by set \(X\), we have:

  • \(X^\pm = X\cup X^{-1}\)

  • \(X^+\) is all non-empty strings

  • \(X^*\) is all strings

  • \(A^*\) with \(A=X^\pm\) is all words over \(X\)

Equivalence
Relations

an equivalence relation \(\sim \) is binary relationship that, for all \(x,y,z\) in a set \(X\), is:

  • reflexive — \(x\sim x\)

  • symmetric — \(x\sim y \iff y\sim x\)

  • transitive — \(x\sim y, y\sim z \implies x\sim z\)

allows us to partition \(X\) into disjoint equivalence classes (example: \(\text{mod}(3)\) partitions \(\mathbb{Z}\) into the classes \([0], [1], [2]\))

an equivalence relation is called a congruence in a semigroup \(S\) if

\( s_1 \sim s_2, t_1 \sim t_2 \implies s_1t_1 \sim s_2t_2 \)

an equivalence relation is called a congruence in a semigroup \(S\) if

\( s_1 \sim s_2, t_1 \sim t_2 \implies s_1t_1 \sim s_2t_2 \)

we then define \(S /\sim \) to be the semigroup where the elements \([s]=\{t\in S \mid t\sim s\}\) are the equivalence classes of \(S\), such that \([s_1][s_2]=[s_1s_2]\)

Relations &
Presentations

Put simply, a presentation is a more efficient way of communicating a group's elements and behavior.

For a semigroup \(S\), let \(\mathcal{R} = \{(\alpha_i,\beta_i): i \in I\}\) be a set of pairs of words from \(X^+\), called relations, where \(\alpha_i =_S \beta_i\) for each \(i\).

For a semigroup \(S\), let \(\mathcal{R} = \{(\alpha_i,\beta_i): i \in I\}\) be a set of pairs of words from \(X^+\), called relations, where \(\alpha_i =_S \beta_i\) for each \(i\).

\(\mathcal{R}\) is a set of defining relations for \(S\), and \(\text{Sgp}\langle X \mid \mathcal{R} \rangle\) is a presentation for \(S\) if:

  • \(\sim \) is the smallest congruence on \(X^+\) containing \(\mathcal{R}\)

  • \(S \cong X^+ / \sim \)

For a monoid \(M\), let \(\mathcal{R} = \{(\alpha_i,\beta_i): i \in I\}\) be a set of pairs of words from \(X^*\), called relations, where \(\alpha_i =_M \beta_i\) for each \(i\).

\(\mathcal{R}\) is a set of defining relations for \(M\), and \(\text{Mon}\langle X \mid \mathcal{R} \rangle\) is a presentation for \(M\) if:

  • \(\sim \) is the smallest congruence on \(X^*\) containing \(\mathcal{R}\)

  • \(M \cong X^* / \sim \)

For a group \(G = \langle X\rangle\), let \(R=\{\alpha_i \mid i\in I\}\) be a set of elements, called relators, such that \(\alpha =_G \varepsilon\). We let \(\sim \) be some congruence on \(A^*\) containing \( \{(aa^{-1}, \varepsilon),(a^{-1} a, \varepsilon) \mid a \in X\} \).

For a group \(G = \langle X\rangle\), let \(R=\{\alpha_i \mid i\in I\}\) be a set of elements, called relators, such that \(\alpha =_G \varepsilon\). We let \(\sim \) be some congruence on \(A^*\) containing \( \{(aa^{-1}, \varepsilon),(a^{-1} a, \varepsilon) \mid a \in X\} \).

\(R\) is a set of defining relators for \(G\), and \(\langle X \mid R \rangle\) is a presentation for \(G\) if:

  • \(\sim \) is the smallest congruence on \(A^*\) containing \( \{(\alpha, \varepsilon) \mid \alpha \in R \} \cup \{ (aa^{-1}, \varepsilon) \mid a \in X \} \cup \{ (a^{-1}a, \varepsilon) \mid a \in X \} \)

  • \(G \cong A^* / \sim \)

a semigroup/monoid/group is finitely presentable if both the set of generators \(X\) and the set of relations \(\mathcal{R}\) (or relators \(R\)) are finite

a semigroup \(S\) with presentation \(\text{Spg}\langle X \mid \rangle \) is called a free semigroup on \(X\); \(S\cong X^+\)

a monoid \(M\) with presentation \(\text{Mod}\langle X \mid \rangle \) is called a free monoid on \(X\); \(M \cong X^*\)

a group \(F\) with presentation \(\langle X \mid \rangle \) is called a free group on \(X\)

a group \(F\) with presentation \(\langle X \mid \rangle \) is called a free group on \(X\)

  • if \(|X| = k\), then \(F\) is the free group of rank \(k\)

  • \(F(X)\) is the free group on \(X\)

  • \(F_k\) denotes a free group of rank \(k\)

A word \(w\) is reduced if

  • it has a unique presentation of the form \(x_1^{\varepsilon_1}, x_2^{\varepsilon_2}, ... x_n^{\varepsilon_n}\) where \(n \geq 0, x_i \in X, \varepsilon_i \in \{1, -1\} \forall i\)

  • we do not have both \(x_i = x_{i+1}\) and \(\varepsilon_i = -\varepsilon_{i+1}\) for any \(i\), AKA there is no \(x\) followed by or following its inverse

If a reduced word \(w \neq x^{-1}vx\) or \(xvx^{-1}\) for some \(x\in X\) and \(v \in A^*\), then \(w\) is cyclically reduced.

Each word \(v \in A^* \) is equal in \(F(X)\) to a unique reduced word \(w\).
