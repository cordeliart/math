Quantifiers

Quantifiers

universal quantifier \(\forall\) — "for all"

  • For all weekends, I do not have to go to school.

  • For all even numbers, the remainder when divided by two is zero.

  • \(\forall x\) in the real numbers, \(x^2\) is even

existential quantifier \(\exists\) — "there exists"

  • There exists a California State University in San Jose.

  • There exists a person with short hair.

  • \(\exists x\) such that \(x^3=8\)

A Combined Example:

Every rose has a petal.

\(\equiv\) For every rose, there exists a petal.

\(\equiv \forall\) rose, \(\exists\) petal

\(\equiv \forall r\) \(\exists p\)

Order Matters

When working with nested quantifiers (multiple quantifiers at once), order is very important. Let's learn the difference by looking at some examples:

\(\forall x\) \(\exists y\): Every \(x\) can have a different \(y\).

\(\forall x\) \(\exists y\) such that \(x\cdot y=0\)

This is read: "For all \(x\), there is a \(y\) such that \(x\cdot y=0\)."

This statement is TRUE, because for each \(x\), we can pick the corresponding \(y\) to be \(0\).

\(\forall x\) \(\exists y\) such that \(x+y=0\)

This is read: "For all \(x\), there is a \(y\) such that \(x+y=0\)."

This statement is TRUE, because for each \(x\), we can pick the corresponding \(y\) to be \(-x\).

\(\exists y\) \(\forall x\): One \(y\) needs to work with all \(x\)'s.

\(\exists y\) \(\forall x\)   \(x\cdot y=0\)

This is read: "There exists a \(y\) such that for all \(x\), \(x\cdot y=0\)."

This statement is TRUE, because for \(y=0\) works for all \(x\)'s.

\(\exists y\) \(\forall x\)   \(x+y=0\)

This is read: "There exists a \(y\) such that for all \(x\), \(x+y=0\)."

This statement is FALSE, because we can't find one \(y\) that works for all \(x\)'s.

Negation with Quantifiers

\( \forall x\) \(P(x)\) negated becomes \(\exists x\) \(\neg P(x)\)

\( \exists x\) \(P(x)\) negated becomes \(\forall x\) \(\neg P(x)\)
